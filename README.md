# Approximation Algorithms

Lecture notes on approximation algorithms: performance guarantees and how to prove them; algorithms, worst-case analyses and tight instances for the knapsack problem, bin packing, the metric TSP and scheduling on identical parallel machines; approximation schemes; the limits of approximation for vertex coloring, maximum clique and the general TSP. With exercises and worked solutions, slides, Colab notebooks and interactive apps.

**Website: [fabiofurini.github.io/approximation-algorithms](https://fabiofurini.github.io/approximation-algorithms/)** — Italian version: [fabiofurini.github.io/algoritmi-di-approssimazione](https://fabiofurini.github.io/algoritmi-di-approssimazione/).

Prerequisites: [Combinatorial Optimization](https://fabiofurini.github.io/combinatorial-optimization/) (the problems) and [Heuristic Algorithms](https://fabiofurini.github.io/heuristic-algorithms/) (the algorithms analysed here).
